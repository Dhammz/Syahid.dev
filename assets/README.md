# Slot CV

1. Salin file CV Anda ke folder `assets` ini.
2. Ubah nama file menjadi **`CV-ANDA.pdf`**.
3. Tombol **Download CV** pada halaman portofolio akan otomatis mengunduh file tersebut.

Jika ingin memakai nama lain, ubah nilai `href` tombol Download CV di `../index.html`.

## Slot foto profil

1. Salin foto portrait Anda ke folder ini.
2. Ubah nama file menjadi **`foto-profil.jpg`**.
3. Foto akan otomatis muncul pada bagian **About** di halaman portofolio.

Gunakan foto dengan rasio 4:5 atau 1:1. File `.png` juga boleh, tetapi Anda perlu mengganti `foto-profil.jpg` menjadi `foto-profil.png` pada `../index.html`.
