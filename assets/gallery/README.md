# Organization Gallery Assets

Letakkan file foto kegiatan / dokumentasi organisasi Anda di folder ini:
- `hmif-unsil.jpg` (Foto kegiatan HMIF UNSIL)
- `it-bootcamp.jpg` (Foto kegiatan IT Bootcamp 2026)
- `ombus.jpg` (Foto pengamanan / koordinasi OMBUS 2026)
- `iconfest.jpg` (Foto penggalangan dana / divisi ICONFEST)
- `orientation.jpg` (Foto orientasi mahasiswa baru UNSIL)

Format yang didukung: JPG, PNG, WebP. Jika file belum ada, galeri otomatis menampilkan kartu visual kosmik gradien yang rapi dan elegan!
